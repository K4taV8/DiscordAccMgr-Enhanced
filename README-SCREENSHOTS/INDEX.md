# Captures d'écran pour le README

Captures de présentation de **Discord Account Manager - Enhanced**, destinées au README et à un collage visuel.

- Interface en français
- Thème Sombre
- Résolution native des fenêtres : 1202 × 864 px
- Données, noms et avatars anonymisés pour la présentation

## Fichiers

| Fichier | Contenu |
|---|---|
| `01-connexion.png` | Écran de connexion avec un compte de démonstration |
| `02-amis.png` | Liste des amis |
| `03-serveurs.png` | Liste des serveurs |
| `04-messages-prives.png` | Liste des messages privés |
| `05-groupes.png` | Liste des groupes |
| `06-archives.png` | Import d'une archive Discord |
| `07-profil.png` | Fiche du profil connecté, version de démonstration |
| `08-informations.png` | Modale Informations, version et dépôts |
| `09-nettoyage.png` | Modes de nettoyage et barre d'actions |
| `10-themes.png` | Sélecteur de thèmes |
| `readme-presentation.png` | Planche de présentation 1920 × 1280 avec les 10 captures |

## Usage

Le prompt prêt à coller dans Gemini se trouve dans `PROMPT-GEMINI.md`. Les captures peuvent aussi être utilisées séparément dans le README.

Les captures ne contiennent pas de jetons, d'identifiants de compte en clair ni de noms de tiers. Les noms affichés sont des libellés de démonstration.
